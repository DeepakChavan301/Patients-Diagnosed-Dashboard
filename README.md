# 🏥 Patients Diagnosed Dashboard

## 📊 Project Overview

The **Patients Diagnosed Dashboard** is an interactive Power BI project designed to analyze patient health and demographic data.

The dashboard provides a summarized view of **5,191 patients** and helps analyze different factors such as:

- Health risk
- Heart attack risk
- Stroke risk
- Smoking risk
- Exercise duration
- Gender
- Ethnicity
- Occupation
- Average weight
- Patient risk categories

The main objective of this project is to transform raw patient data into an interactive dashboard that can be used to understand important patterns and generate meaningful insights.

# 🎯 Project Objectives

The main objectives of this project are:

1. Analyze the total number of patients.
2. Calculate important patient-related KPIs.
3. Analyze heart attack and stroke risk.
4. Identify patients belonging to high/moderate-risk categories.
5. Analyze patients with limited exercise duration.
6. Identify high-risk smokers.
7. Analyze patients by gender.
8. Analyze patients by ethnicity.
9. Compare patient distribution across occupation types.
10. Analyze average weight across occupation categories.
11. Present all important findings through an interactive Power BI dashboard.
